# OMP Desktop 0.3.0

## Português (Brasil)

Primeiro release público do cliente desktop independente para **oh-my-pi (OMP)**, com instalador **Windows x64**.

### Destaques

- Interface Bancada, temas claro/escuro, painéis redimensionáveis e gavetas em janelas estreitas.
- Português brasileiro, inglês dos EUA e chinês simplificado.
- Assistente inicial em cinco etapas, seleção do modelo padrão e busca de contas/provedores.
- Conversa com ferramentas em streaming, fila, pausa após o passo atual e acompanhamento dos subagentes no painel.
- Aprovações explícitas, histórico persistido sem reenviar prompts, diff Git e terminal PTY.
- Correções de rolagem em históricos longos, restauração de sessões, conflitos de configuração, teclado e contraste.

### Instalação e verificação

1. Instale o **OMP** separadamente. Versão de referência: **18.16.0**. Git só é necessário para o painel Alterações.
2. Baixe `OMP-Desktop-0.3.0-setup.exe` e `SHA256SUMS.txt` deste release.
3. Compare o SHA-256 do arquivo: `Get-FileHash .\OMP-Desktop-0.3.0-setup.exe -Algorithm SHA256`.
4. Execute o instalador por usuário. O runtime Bun está incluído; o executável OMP não está.

**O instalador não é assinado e não há atualização automática.** O SmartScreen pode exibir um aviso; verifique a origem e o hash. Não desative os recursos de segurança do Windows.

A revisão de dependências corrigiu o DOMPurify, inclusive a cópia interna do Monaco. Permanecem dois avisos transitivos documentados, com análise de alcance e prazo de revisão: [segurança do release](https://github.com/ricarossetto/omp-desktop/blob/v0.3.0/docs/release-security.md). Não é uma auditoria sem achados nem certificação de segurança ou acessibilidade.

[Manual completo em português](https://github.com/ricarossetto/omp-desktop/blob/v0.3.0/README.md).

## English (US)

First public release of the independent desktop client for **oh-my-pi (OMP)**, for **Windows x64**.

- Light/dark themes, resizable panels, narrow-window drawers, and three interface languages.
- Five-step onboarding, default model selection, and account/provider search.
- Streaming tools, message queues, pause after the current step, subagent details, explicit approvals, Git diff, and a real PTY terminal.
- Fixes for long-history scrolling, session restoration without resending prompts, configuration conflicts, keyboard handling, and contrast.

Install **OMP separately** (validated baseline: **18.16.0**). Bun is bundled; the OMP executable is not. Download the `.exe` and `SHA256SUMS.txt`, then verify the checksum with `Get-FileHash` before running the per-user installer.

**Unsigned installer; no auto-update.** Do not disable Windows security features to bypass a warning. Two transitive dependency advisories remain documented in the [release security review](https://github.com/ricarossetto/omp-desktop/blob/v0.3.0/docs/release-security.md).

[Full English manual](https://github.com/ricarossetto/omp-desktop/blob/v0.3.0/docs/README.en-US.md).

## 简体中文

面向 **Windows x64** 的 **oh-my-pi（OMP）独立桌面客户端**首次公开发布。

- 浅色/深色主题、可调整大小的面板、窄窗口抽屉，以及葡萄牙语、英语和简体中文界面。
- 五步首次使用引导、默认模型选择、账户与提供商搜索。
- 流式工具输出、消息队列、当前步骤结束后暂停、子智能体详情、明确审批、Git 差异和真实 PTY 终端。
- 修复长历史滚动、会话恢复时不重发提示词、配置冲突、键盘操作和对比度问题。

请**单独安装 OMP**（已验证基线：**18.16.0**）。安装程序包含 Bun，但不包含 OMP 可执行文件。下载 `.exe` 和 `SHA256SUMS.txt`，使用 `Get-FileHash` 核对 SHA-256 后，再运行按用户安装的程序。

**安装程序未签名，也没有自动更新。** 请勿关闭 Windows 安全功能来绕过警告。仍有两个传递依赖安全公告，详见[发布安全审查](https://github.com/ricarossetto/omp-desktop/blob/v0.3.0/docs/release-security.md)。
