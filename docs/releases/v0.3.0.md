# OMP Desktop 0.3.0

First public release of the independent desktop client for **oh-my-pi (OMP)**, for **Windows x64**.

## Highlights

- Bancada interface with light/dark themes, resizable panels, and drawers in narrow windows.
- Brazilian Portuguese, US English, and Simplified Chinese.
- Five-step first-run assistant, default model selection, and account/provider search.
- Streaming tool output, message queue, pause after the current step, and subagent tracking in the panel.
- Explicit approvals, persisted history without resending prompts, Git diff, and a real PTY terminal.
- Fixes for scrolling in long histories, session restoration, configuration conflicts, keyboard handling, and contrast.

## Installation and verification

1. Install **OMP** separately (validated baseline: **18.16.0**), or let the first-run assistant install it: when OMP is missing, the Environment step and diagnostics offer **Install OMP**, and nothing runs until you click **Install OMP**. The app downloads the pinned **18.16.0** Windows binary from the same official build service used by OMP's Windows installer (`build.stencil.so`) to `%LOCALAPPDATA%\omp\omp.exe`, verifies the published SHA-256 and `omp.exe --version`, and never overwrites an existing file. It does not change the persistent PATH or registry and does not touch `~/.omp`. The install reports progress (resolving, downloading, verifying, activating) and ends in success or an actionable error; on success, the app detects the real executable and updates diagnostics without restarting or losing your draft or language. Manual `omp.exe` selection remains available. Git is only needed for the Changes panel.
2. Download `OMP-Desktop-0.3.0-setup.exe` and `SHA256SUMS.txt` from this release.
3. Compare the file's SHA-256:

   ```powershell
   Get-FileHash .\OMP-Desktop-0.3.0-setup.exe -Algorithm SHA256
   ```

4. Run the per-user installer. The Bun runtime is bundled; the OMP executable is not.

**Optional tools.** Git (Changes panel) and Node.js LTS (projects/MCP) can be installed from the app with an explicit confirmation. Git uses the official Git for Windows MinGit **2.56.0.windows.4** ZIP; Node.js uses the **current LTS resolved from nodejs.org at install time** (v26.13.0 at release). Both verify SHA-256, install into `%LOCALAPPDATA%\omp-desktop\tools`, require no administrator rights, never overwrite a global tool, and do not change the persistent PATH or registry. New terminals and OMP child processes see them without restarting running agents. Neither is required to open the app or OMP; Bun is bundled.

**The installer is unsigned and there is no auto-update.** SmartScreen may show a warning; verify the origin and the hash. Do not disable Windows security features. To upgrade later, download the new installer and install it over the current version.

## Dependency review

The dependency review fixed DOMPurify, including Monaco's internal copy. Two transitive advisories remain documented with scope analysis and a review date in the [release security review](https://github.com/ricarossetto/omp-desktop/blob/v0.3.0/docs/release-security.md). The official `@oh-my-pi/pi-coding-agent` 18.16.0 package contains upstream static debug certificate/key constants; these are public third-party debug material, not user credentials, and are documented in the same review. The payload contains no real user credentials, tokens, or account data. This is not an audit with no findings and not a security or accessibility certification.
