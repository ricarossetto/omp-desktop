# OMP Desktop 0.3.1

Release 0.3.1 of the independent desktop client for **oh-my-pi (OMP)**, for **Windows x64** and **Linux x86_64**.

## Highlights

- **Long-history fix.** The desktop no longer drops old messages or replaces content with a size marker to fit the 8 MiB desktop budget. The reported long-history case (235 messages omitted) and a ~29 MiB history with Unicode and deep tool details are covered by regression tests. Messages, Unicode text, and deep tool arguments/results/details now cross host → main → preload → renderer intact, survive reload, and stay stable after the post-settle sync. The upstream OMP frame limit is unchanged (1 MB default, up to 64 MiB).
- **Linux x86_64 packages.** Debian 12/13 and Ubuntu 24.04/26.04 `.deb`, a `.tar.gz` for local use, and an Arch Linux package built from `packaging/arch/PKGBUILD`. The app installs under `/opt/omp-desktop`, with `/usr/bin/omp-desktop`, a desktop entry, icons, licenses, and the sandbox enabled. The Bun 1.4.4 runtime is bundled; OMP is not.
- **Windows x64.** The per-user NSIS installer remains unsigned and per-user, with bundled Bun 1.4.4 and no auto-update.
- **Optional tools.** Git (Changes panel) and Node.js LTS (projects/MCP) remain optional and are installed only after explicit confirmation, from official sources, with SHA-256 verification and no persistent PATH/registry changes. On Linux, Git stays native and the app only shows the distribution command; Node.js LTS is installed under the XDG data directory.

No ARM, macOS, AppImage, AUR, PPA, or auto-update channel is part of this release.

## Assets and verification

This release publishes four binaries and one checksum file:

| Platform | Asset |
| --- | --- |
| Windows x64 | `OMP-Desktop-0.3.1-setup.exe` |
| Debian/Ubuntu x86_64 | `OMP-Desktop-0.3.1-linux-amd64.deb` |
| Linux x86_64 (tar.gz) | `OMP-Desktop-0.3.1-linux-x64.tar.gz` |
| Arch Linux x86_64 | `omp-desktop-0.3.1-1-x86_64.pkg.tar.zst` |
| Checksums | `SHA256SUMS` |

`SHA256SUMS` contains the SHA-256 of all four assets. Verify the downloaded files before installing:

```bash
sha256sum -c SHA256SUMS
```

On Windows:

```powershell
Get-FileHash .\OMP-Desktop-0.3.1-setup.exe -Algorithm SHA256
```

Compare the result with the `OMP-Desktop-0.3.1-setup.exe` line in `SHA256SUMS`.

## Installation

**Windows x64.** Download `OMP-Desktop-0.3.1-setup.exe`, verify the hash, and run the per-user installer. It does not request administrator rights. Install OMP separately (validated baseline **18.16.0**), or use **Install OMP** in the first-run assistant: the app downloads the pinned official Windows binary from the official build service, verifies the published SHA-256 and `omp.exe --version`, and never overwrites an existing file. The installer is unsigned and there is no auto-update; SmartScreen may warn. Do not disable Windows security features.

**Debian/Ubuntu x86_64.**

```bash
sudo apt install ./OMP-Desktop-0.3.1-linux-amd64.deb
```

`apt` resolves the Electron dependencies declared by the package. The app is installed under `/opt/omp-desktop` with `/usr/bin/omp-desktop`.

**Linux tar.gz x86_64.** Extract `OMP-Desktop-0.3.1-linux-x64.tar.gz` and run the `omp-desktop` executable inside the extracted directory. The archive is also the local source used by the Arch PKGBUILD.

**Arch Linux x86_64.**

```bash
sudo pacman -U omp-desktop-0.3.1-1-x86_64.pkg.tar.zst
```

The package is built from `packaging/arch/PKGBUILD`. The PKGBUILD verifies the local `OMP-Desktop-0.3.1-linux-x64.tar.gz` against a trusted SHA-256 from `OMP_DESKTOP_ARCHIVE_SHA256` or `SHA256SUMS`; it does not compute the checksum from the artifact itself and has no `SKIP`.

The Linux packages are unsigned and there is no auto-update. Git is native and is not installed by the app; Node.js LTS is optional. The app never runs with `--no-sandbox`.

## Dependency review

The dependency review, residual advisories, and the upstream debug certificate/key material in the official `@oh-my-pi/pi-coding-agent` package are documented in the [release security review](https://github.com/ricarossetto/omp-desktop/blob/v0.3.1/docs/release-security.md). The payload contains no real user credentials, tokens, or account data. This is not an audit with no findings and not a security or accessibility certification.

# OMP Desktop 0.3.1 (Português do Brasil)

Versão 0.3.1 do cliente desktop independente para **oh-my-pi (OMP)**, para **Windows x64** e **Linux x86_64**.

## Destaques

- **Correção de histórico longo.** O desktop não descarta mais mensagens antigas nem substitui conteúdo por um marcador para caber no orçamento de 8 MiB. O caso relatado de histórico longo (235 mensagens omitidas) e um histórico de ~29 MiB com Unicode e detalhes profundos de ferramentas estão cobertos por testes de regressão. O conteúdo é preservado ao carregar a conversa, recarregar a janela e concluir uma resposta. Os limites do protocolo do OMP continuam os mesmos (1 MB padrão, até 64 MiB).
- **Pacotes Linux x86_64.** `.deb` para Debian 12/13 e Ubuntu 24.04/26.04, `.tar.gz` para uso local e pacote Arch Linux gerado pelo `packaging/arch/PKGBUILD`. O app instala em `/opt/omp-desktop`, com `/usr/bin/omp-desktop`, entrada de desktop, ícones, licenças e sandbox habilitado. O Bun 1.4.4 é embutido; o OMP não.
- **Windows x64.** Instalador NSIS por usuário, não assinado, com Bun 1.4.4 embutido e sem auto-update.
- **Ferramentas opcionais.** Git (painel Changes) e Node.js LTS (projetos/MCP) continuam opcionais, instalados somente após confirmação explícita, de fontes oficiais, com verificação SHA-256 e sem alterar PATH/registro persistentes. No Linux, o Git é nativo e o app apenas mostra o comando da distribuição; o Node.js LTS vai para o diretório XDG.

Não fazem parte desta versão: ARM, macOS, AppImage, AUR, PPA ou canal de auto-update.

# OMP Desktop 0.3.1（简体中文）

面向 **oh-my-pi (OMP)** 的独立桌面客户端 **0.3.1** 版本，支持 **Windows x64** 和 **Linux x86_64**。

## 亮点

- **长历史记录修复。** 桌面端不再丢弃旧消息，也不会为了满足 8 MiB 预算而用标记替换内容。已报告的 235 条消息被省略的长历史场景，以及约 29 MiB、包含 Unicode 和深层工具详情的场景，均由回归测试覆盖。消息、Unicode 文本以及深层工具参数/结果/详情现在可以完整通过 host → main → preload → renderer，重载后仍然存在，并在 settle 后同步中保持稳定。上游 OMP 的帧限制不变（默认 1 MB，最高 64 MiB）。
- **Linux x86_64 软件包。** 提供 Debian 12/13 和 Ubuntu 24.04/26.04 的 `.deb`、本地使用的 `.tar.gz`，以及由 `packaging/arch/PKGBUILD` 构建的 Arch Linux 包。应用安装到 `/opt/omp-desktop`，包含 `/usr/bin/omp-desktop`、桌面入口、图标、许可证，并启用 sandbox。内置 Bun 1.4.4，不内置 OMP。
- **Windows x64。** 按用户安装的 NSIS 安装包，未签名，内置 Bun 1.4.4，无自动更新。
- **可选工具。** Git（Changes 面板）和 Node.js LTS（项目/MCP）仍为可选，仅在明确确认后从官方来源安装，校验 SHA-256，不修改持久 PATH/注册表。Linux 上 Git 使用系统原生版本，应用只显示对应发行版的命令；Node.js LTS 安装到 XDG 数据目录。

本版本不包含 ARM、macOS、AppImage、AUR、PPA 或自动更新通道。

| Linux x86_64（tar.gz） | `OMP-Desktop-0.3.1-linux-x64.tar.gz` |
| Arch Linux x86_64 | `omp-desktop-0.3.1-1-x86_64.pkg.tar.zst` |

## 安装

**Windows x64。** 下载 `OMP-Desktop-0.3.1-setup.exe`，校验哈希后运行按用户安装程序。它不会请求管理员权限。请单独安装 OMP（已验证基线 **18.16.0**），或在首次运行助手中选择 **Install OMP**：应用会从官方构建服务下载固定版本的官方 Windows 二进制，校验发布的 SHA-256 和 `omp.exe --version`，且从不覆盖已有文件。安装包未签名，也没有自动更新；SmartScreen 可能提示。不要禁用 Windows 安全功能。

**Debian/Ubuntu x86_64。**

```bash
sudo apt install ./OMP-Desktop-0.3.1-linux-amd64.deb
```

`apt` 会解析软件包声明的 Electron 依赖。应用安装到 `/opt/omp-desktop`，并提供 `/usr/bin/omp-desktop`。

**Linux tar.gz x86_64。** 解压 `OMP-Desktop-0.3.1-linux-x64.tar.gz`，运行解压目录中的 `omp-desktop`。该归档也是 Arch PKGBUILD 使用的本地源。

**Arch Linux x86_64。**

```bash
sudo pacman -U omp-desktop-0.3.1-1-x86_64.pkg.tar.zst
```

该包由 `packaging/arch/PKGBUILD` 构建。PKGBUILD 使用 `OMP_DESKTOP_ARCHIVE_SHA256` 或 `SHA256SUMS` 中的可信 SHA-256 校验本地 `OMP-Desktop-0.3.1-linux-x64.tar.gz`；它不会从产物本身计算校验和，也没有 `SKIP`。

Linux 软件包未签名，也没有自动更新。Git 使用系统原生版本，应用不会安装 Git；Node.js LTS 为可选。应用从不以 `--no-sandbox` 运行。
